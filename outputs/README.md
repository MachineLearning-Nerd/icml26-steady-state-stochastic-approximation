# Output provenance

This repository contains two output generations.

## Authoritative current evidence

Use .openresearch/artifacts and the claim-specific files under
release/hf-space-overlay/evidence. Claims 1–5 are the current
VERIFIED_SCOPED finite-contract results. Claim 6 is BLOCKED, with its four
routes documented under .openresearch/artifacts/claim_6/routes.md.

## Historical compatibility output

outputs/verdict.json and outputs/verify_run.log are retained from the original
small 1D judged surface. They report 6/6 toy checks and are useful for
lineage, but they do not establish the current d=8 claims. Do not cite them
as the authoritative publication result.

The frozen entrypoint regenerates the current campaign artifacts. Use the
claim directories and their independent checker outputs when reporting the
repository status.
