# Method — Claim 5

Each binary coordinate is retained with probability `rho` and otherwise
resampled from its stationary skew Bernoulli law. This transition kernel is a
Doeblin refresh kernel, so the eight-coordinate product is uniformly ergodic.
The standardized output has autocorrelation `rho^m`, giving long-run variance
`(1+rho)/(1-rho)`. All three d=8 model families and the tail grid are rerun.
Tail uncertainty uses the same exact two-sided 95% Clopper-Pearson construction
as Claim 4.
